## Intuición

Elegí un signo y mové *a*. Mirá qué números quedan pintados.

- ¿Qué cambia entre **>** y **≥**?
- Prendé **Probar un número** y arrastrá el punto: ¿cuándo está y cuándo no?

## Explicación

- Los signos:
  - $>$ mayor, $<$ menor.
  - $\geq$ mayor o igual, $\leq$ menor o igual.
- Truco: la "boquita" del signo se abre hacia el más grande: $5 > 2$.
- $x > 2$ no es un número solo: son **todos** los números mayores que 2 (2.1, 3, 100…). Muchísimos, por eso se pintan en la recta.
- Un **intervalo** es una forma corta de escribirlos:
  - **corchete** $[\;]$ = la punta **está** (punto relleno);
  - **paréntesis** $(\;)$ = la punta **no está** (punto hueco).
- El infinito ($+\infty$ o $-\infty$) **siempre** va con paréntesis: no es un número, nunca se llega.
- "Entre dos números": $2 < x \leq 5$ es el intervalo $(2, 5]$.

## Para recordar

| Desigualdad | Intervalo |
|---|---|
| $x > 2$ | $(2, +\infty)$ |
| $x \geq 2$ | $[2, +\infty)$ |
| $x < 2$ | $(-\infty, 2)$ |
| $x \leq 2$ | $(-\infty, 2]$ |
| $2 < x \leq 5$ | $(2, 5]$ |

- Todos los números: $\mathbb{R}$. Ninguno: $\varnothing$.

## Ejemplo resuelto

Escribí como intervalo "los números mayores o iguales que $-1$ y menores que $4$".

### Paso 1: la desigualdad

$-1 \leq x < 4$.

### Paso 2: las puntas

El $-1$ está (≤): corchete. El $4$ no está (<): paréntesis.

### Paso 3: el intervalo

$[-1, 4)$.

## Ejercicios

### Nivel: Para arrancar

### ¿Está?

¿El 3 está en $x \geq 3$?

- [x] Sí
- [ ] No

### Mayor

¿Cuál es el intervalo de $x > 4$?

- [ ] $[4, +\infty)$
- [x] $(4, +\infty)$
- [ ] $(-\infty, 4)$

### Menor o igual

¿Cuál es el intervalo de $x \leq -2$?

- [x] $(-\infty, -2]$
- [ ] $(-\infty, -2)$
- [ ] $[-2, +\infty)$

### Nivel: Para animarse

### Entre dos

¿Cuál es el intervalo de $1 \leq x < 6$?

- [ ] $(1, 6]$
- [x] $[1, 6)$
- [ ] $[1, 6]$

### Al revés

¿Qué desigualdad es el intervalo $(-3, 0]$?

- [x] $-3 < x \leq 0$
- [ ] $-3 \leq x < 0$
- [ ] $x > -3$

### Contar

¿Cuántos números **enteros** hay en $[2, 5)$?

respuesta: 3

pista: Escribilos: ¿el 2 está? ¿Y el 5?

#### Resolución

Están el 2, el 3 y el 4. El 5 no (paréntesis).

### Negativos

¿Cuál es el número entero **más grande** que cumple $x < -1$?

respuesta: -2

pista: Pensá en la recta: a la izquierda del −1.

## Para tutores

### Objetivo

- Leer y escribir desigualdades, y pasarlas a la recta y a intervalo.

### Antes tiene que saber

- [Sumar y restar con signos](tema:sumar-y-restar-con-signos) (ubicar negativos en la recta).

### Errores típicos

- Confundir $>$ con $<$.
- Pensar que $x > 2$ es "el 3".
- Poner corchete en el infinito.
- Con negativos: creer que $-5 > -2$.

### Cómo destrabarlo

- Para $>$ y $<$: "la boca abierta mira al más grande".
- Con negativos, ir a la recta: el que está más a la derecha es el mayor.
- $x > 2$ no es un número: pedir tres ejemplos, y alguno con decimales (2.5, 2.01).
- Al infinito no se llega nunca: por eso siempre lleva paréntesis.

### En el pizarrón

- Dibujar la recta, el punto (hueco o relleno) y pintar hacia el lado que corresponde.
- Tres renglones para decir lo mismo: con palabras ("los mayores que 2"), en la recta y como intervalo $(2, +\infty)$.
- Repetir con $x \leq 5$ y con $-1 \leq x < 3$.
- Hacer un cuadrito: punto relleno, corchete, $\leq$ o $\geq$ van juntos; punto hueco, paréntesis, $<$ o $>$ van juntos.

### Preguntas para el alumno

- ¿El 2 está en $(2, 5]$? ¿Y el 5?
- Nombrá tres números que cumplan $x \leq 0$.
- ¿Cuál es el número más chico que cumple $x > 2$? (No hay: sirve para charlar.)
- Escribí como intervalo "los números entre $-3$ y 0, incluidos los dos".
